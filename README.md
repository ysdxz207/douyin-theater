# 抖音追剧助手

用于在抖音视频播放页调整弹幕、清屏、画质、连播和全屏设置。

## 安装

1. 将项目文件夹保存到本地。加载时选择包含 `manifest.json` 的 `douyin-theater` 文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择 `douyin-theater` 文件夹。
5. 安装完成后，可在 Chrome 的扩展程序菜单中将「抖音追剧助手」固定到工具栏。

## 使用

1. 在 Chrome 中打开抖音视频播放页。
2. 点击工具栏上的「抖音追剧助手」图标。
3. 按需设置播放选项，然后点击绿色大按钮「进入追剧模式」。
4. 再次点击大按钮退出追剧模式。处于全屏播放时，也可按 `Esc` 退出并恢复进入前的播放器设置。

设置默认开启。调整小开关后，点击大按钮应用设置。

| 选项 | 作用 |
| --- | --- |
| 隐藏弹幕 | 隐藏播放器内显示的弹幕。 |
| 清屏 | 开启抖音播放器的清屏模式。 |
| 最高画质 | 选择当前视频可用的最高画质。 |
| 合集连播 | 开启播放器连播；播放页有明确关联的合集时切换到合集。未找到关联合集时保留当前视频。 |
| 全屏播放 | 全屏显示播放器。浏览器全屏不可用时，扩展会尝试铺满页面显示。 |

## 更新扩展

修改扩展文件后，打开 `chrome://extensions`，点击「抖音追剧助手」卡片上的重新加载按钮。重新打开扩展弹窗即可连接已打开的抖音页面，通常不需要刷新抖音标签页。

## 故障处理

- **没有找到抖音标签页**：在当前 Chrome 窗口打开抖音页面，再打开扩展弹窗。
- **尚未找到播放器**：打开具体的视频播放页，等待播放器加载后重新打开弹窗，或直接点击大按钮重试。
- **扩展无法连接页面**：先在 `chrome://extensions` 重新加载扩展，再打开弹窗重试。
